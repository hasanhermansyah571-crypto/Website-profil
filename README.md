# Website Profil Bisnis Asep Suherman

File website sederhana untuk dipublikasikan dengan GitHub Pages.

## File
- `index.html` — halaman utama
- `style.css` — tampilan website

## Cara pasang di GitHub Pages
1. Buat repository baru di GitHub, misalnya `profil-bisnis`.
2. Upload `index.html` dan `style.css`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu **Save**.
6. Tunggu sampai GitHub memberikan alamat seperti:
   `https://USERNAME.github.io/profil-bisnis/`

Gunakan alamat HTTPS tersebut pada kolom **Situs web** di formulir Meta.
